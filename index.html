Features für Enterprise-Teams

📋

Spec-Driven

Alles beginnt mit einer Spezifikation. Requirements, Stories, Refinement – wie im echten SCRUM. Keine AI-Chaos mehr.

🧠

Self-Learning

Nach jeder Story werden Learnings in dos-and-donts.md gespeichert. Agents wiederholen Fehler nicht.

🔀

Multi-LLM per Story

Wähle das LLM pro Story: Claude, GLM, Kimi K2, MiniMax. Optimiere für Kosten, Qualität oder lokale Ausführung.

📊

Kanban Board

Visualisiere Specs und Stories auf einem Kanban Board. Drag & Drop Stories in die Queue. Sehe den Fortschritt live.

⚡

Autonome Queue

Schiebe mehrere Specs in die Queue. Agents arbeiten sie nacheinander ab – ohne dass du dabei sein musst.

🌐

Projektübergreifend

Öffne mehrere Projekte in der Web UI. Queue Specs projektübergreifend. Ein Dashboard für alles.

Git Strategy per Feature

Wähle pro Spec: Feature Branch oder Git Worktree. Parallele Features ohne Konflikte.

Fokus-Commands

Die wichtigsten Workflows für den täglichen Einsatz

/create-spec

Feature-Spezifikation erstellen

PO-Dialog → Clarification → Implementation Plan → User Stories → Architect Refinement

/execute-tasks

Stories ausführen

Git Setup → Implement → Test → Self-Review → Code Review → PR

/add-story

Story zu Spec hinzufügen

Neue Anforderung → Story erstellen → Zum Kanban hinzufügen

/add-bug

Bug mit Root-Cause-Analyse

Bug beschreiben → Analyse → Fix-Story erstellen

/add-todo

Schnelle Aufgabe zum Backlog

Lightweight Task → Backlog → Später abarbeiten

/plan-product

Produkt planen (einmalig)

Product Brief → Tech Stack → Roadmap

Quick Start

In 3 Minuten startklar

1

Global installieren (einmalig)

curl -sSL https://raw.githubusercontent.com/michsindlinger/specwright/main/setup-devteam-global.sh | bash
2

Im Projekt installieren

cd your-project/
curl -sSL https://raw.githubusercontent.com/michsindlinger/specwright/main/setup.sh | bash
curl -sSL https://raw.githubusercontent.com/michsindlinger/specwright/main/setup-claude-code.sh | bash
3

Los geht's

/plan-product # Einmalig: Produkt planen
/create-spec # Feature-Spec erstellen
/execute-tasks # Stories abarbeiten

Voraussetzung: Claude Code CLI muss installiert sein.
